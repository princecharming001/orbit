### Database (pg_stat_statements)

The SQL itself is fast: /sync/status's counts run in about 1 ms. Function time is round trips and per-request
work, not slow queries. The busiest statements:

- `orbit.cron_call_worker()`: 19,934 calls, 13.6 ms mean (the minute cron that wakes the worker)
- `pgmq.read`: 109,372 calls, 0.9 ms (the worker polling each queue)
- calendar upsert: **236,467 calls for 1,010 rows** (every incremental sync rewrites each event, one round trip each)
- `orbit.secret($1)`: 17,326 calls, plus 11,435 `orbit_secret` RPCs over PostgREST (secrets read per invocation)
- people update 57,317 and identity insert 88,760 calls (row-at-a-time ingest)

Advisors: the orbit tables have RLS on with no policies, which is intended (only the functions, as the service
role, read them). 26 unindexed foreign keys in `orbit` (ties, tie_scores, people.merged_into, recommendations,
drafts, ...). The `public` schema findings belong to other apps in this project and are out of scope.

## Findings, ranked

### Critical

1. **/sync/pull failed every time for the main account (RangeError).** 28 of 28 calls in 24h returned 500, so
   nothing the server read (new email, LinkedIn people, scores) reached that browser. The log kept only the
   error's name; with the stack added it read "Invalid time value" in postgres.js's timestamptz serializer. A
   table never pulled starts at `'-infinity'`, which postgres.js turns into a JS Date first, so any account with an
   empty table could never pull. PGlite tests do not go through postgres.js, so nothing caught it. *Fixed:* the
   first pull of a table starts in 1970, with a test that applies postgres.js's check to every pull parameter;
   195 pulls in the next hour, 1 error (a deploy boundary). Also: unexpected errors now log their stack frames,
   pull no longer runs 18 queries in a row, and the 384-float embedding is dropped in SQL.
1b. **Switching accounts in one browser reused the other account's sync cursor,** so returning to an account
   never pulled anything older than that cursor (the account looked emptied). *Fixed in af24ab3* (a parallel
   session): the cursor is reset when the signed-in account changes.
2. **No error boundary.** A failed live query or a missing lazy chunk after a deploy blanks the whole app.
   *Fixed:* a boundary around the routes and the page outlet, with Reload, and one automatic reload for a
   stale chunk.
3. **A pull can overwrite a local edit that has not been pushed yet** (`serverSync.ts` writes server rows
   without checking the outbox). *Fixed:* the outbox is pushed before every pull.

### High: backend latency

4. **Functions reconnected to the database on almost every poll.** The pool closed idle connections after 20 s,
   and the app polls every 3 to 60 s, so a poll usually paid TCP, TLS and the password handshake across regions
   (about 0.6 s of /sync/status's 0.7 s; warm calls take 70 to 160 ms). Measured: making status's round trips
   parallel alone did not move its p50 (720 to 807 ms). *Fixed:* connections stay open 4 minutes.
4b. **Every authed request made 3 sequential database trips before the route ran** (IP limit, session check,
   user limit). *Fixed:* the token is verified locally, then the session check and one combined rate-limit
   write go out together.
5. **/sync/pull ran its 17 table queries and the audit query one after another.** *Fixed:* they run together
   on the pool.
6. **/sync/status counts pending jobs with `message->>'userId'` on every queue, every 3 s,** and the queue
   dedupe check scans `message->>'dedupeKey'` under a lock. *Fixed:* expression indexes on both, on every
   orbit queue (with today's near-empty queues Postgres still picks a plain scan, correctly; the indexes take
   over when a backfill fills them).
7. **The rate-limit sweep deletes expired counters with no index on `expires_at`** (1 call in 50). *Fixed:*
   index.
8. **The audit-log read in pull has no index for `action = 'sync.delete'` by id.** *Fixed:* partial index.
9. **Unipile key and base were read once at cold start;** a warm isolate kept answering 503 after the key was
   stored. Agent routes also lost the stored key (`...deps.agent.env` overwrote it with undefined). *Fixed:*
   a missing provider secret is looked up again (at most once a minute), and the override keeps defined values.
10. **No timeouts on Google token/API calls or Unipile calls;** one hung request holds an isolate. *Fixed for
    Google token and API calls* (15 s). Unipile in orbit-connectors: deferred, see below.
11. **Worker poison messages:** a job that kills the isolate never reaches the dead-letter path and reruns
    forever; batch tails can outlive their visibility timeout and run twice. *Fixed:* a message read too many
    times is dead-lettered before it runs, and each message's visibility is extended right before it runs.

### High: frontend

12. **School-name lookup scans 11,807 schools per logo tile,** and downloads 860 KB, for every unknown
    company, even off screen (484 ms for 50 names). *Fixed:* indexed once, cached per name.
13. **The command palette's live query reads every person on every page and re-runs on every write.** *Fixed:*
    it mounts only while open.
14. **Sync status polls every 3 s until setup ends and never pauses in a hidden tab;** it re-renders listeners
    even when nothing changed. *Fixed:* paused while hidden (checks on return), 60 s once the import is done,
    and listeners hear only real changes.
15. **The outbox loop reads every outbound row each second.** *Fixed:* reads queued and sending rows by index.
16. **The Anthropic SDK is in the first-paint bundle.** *Fixed:* the SDK and the chat loop load on first use
    (the index chunk is 2.10 MB, from 2.36 MB; the SDK is its own 214 KB chunk). The chat agent and tools
    (~408 KB) and the draft templates are still in it: deferred, they are used on the home screen.

### Medium

17. Clients' IP for rate limits came from the first `x-forwarded-for` entry, which a caller can set. *Fixed:*
    the platform's `cf-connecting-ip` / `x-real-ip` first.
18. `/connect/notify` compared its signature with `!==`. *Fixed:* constant-time compare.
19. Unhandled failures leave screens stuck: Company reach skeleton, Map company panel, a redraft whose save
    throws, Morning brief Undo. *Fixed.*
20. Command palette search input had no label. *Fixed.*
21. Calendar sync rewrites every event on every run, one statement each (236k calls). Deferred: needs a
    batched upsert that skips unchanged rows, with tests on recurrence edge cases.
22. orbit-connectors: /mutuals and /posts/activity call Unipile in series with no timeout (10 s routes);
    `/send` is not idempotent; secrets read with about 12 PostgREST calls at cold start. Deferred to a
    connectors pass; the fixes are listed in the backend sweep notes below.
23. Worker runs messages strictly in series with about 6 round trips each. Deferred: concurrency changes
    ordering guarantees the handlers rely on.
24. `/sync/push` applies changes one transaction each. Deferred.
25. Map page runs 8 whole-table live queries; Inbox recomputes ~10 filter chains per render; merges `put`
    rows one at a time; the People route takes about 1 s to render. Deferred (each is a contained refactor).
26. `text-ink-3` on `canvas-2` is 4.43:1, just under AA. Deferred: a palette change is a design decision.
27. Phone More sheet and the activity popover have `role="dialog"` without focus handling. Deferred.

### Low / noted

- Pinning functions to us-west-2 (`forceFunctionRegion`) was measured: on a two-query route the fastest call
  went from 92 to 72 ms, while the median got worse on cold isolates. Not worth losing automatic failover yet;
  revisit if pull or the worker stay slow after the parallel work.
- `postgres.js` `fetch_types` adds a query to each new connection; turning it off would change how array
  columns come back. Left on.
- Refresh-token rotation has no grace window, so two tabs refreshing together can sign one out.
- Secrets travel as `?token=` on two webhook URLs. Switch to per-link HMAC signatures.
- About 35 unused exports; four copies of "latest brief"; `serverSync.queueMemoryDelete` is never called
  (memory deletes may not reach the server).
- Test gaps: `startServerSync` timing and cleanup, pull vs pending edit (added), account-mode merges, the
  cross-tab refresh lock.
- Locally, account-mode unit tests fail because Node's `Request` rejects jsdom's `AbortSignal` (the fake
  orbit-api and `proxy.test.ts`); CI is unaffected. Worth fixing in `src/test/fakeOrbitApi.ts` so they run here.
- The status listener now hears only real changes, which exposed a race: a status that landed between a
  component's first read and its subscribe was lost. Fixed: a new listener gets the current status at once.
